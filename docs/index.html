Fanta OFME Downloader & Cloud Sync

An open-source desktop game manager with direct multi-threaded downloads, automated archive extraction, Steam library shortcut injection, and private Google Drive cloud saves.

Download Latest Release View Source Code

Turbo Downloader

Accelerated multi-threaded downloads with automatic link resolution for GoFile, PixelDrain, BuzzHeavier, and FileDitch.

Automated Extraction

Built-in 7-Zip and WinRAR pipeline that unpacks archives automatically with password handling and post-extract cleanup.

Steam Library Injection

Add installed games directly as non-Steam shortcuts with custom banners and playtime tracking in one click.

Google Drive Cloud Saves

One-click private save sync. Back up your game progress, synchronize saves across computers, and restore whenever needed.

Version Checker & Alerts

Scrapes for game updates in real-time, displays update indicators, and sends Discord webhook notifications.

Open Source & Zero Telemetry

Licensed under MIT. All data remains exclusively on your computer and your personal Google Drive. No analytics or tracking.

Private & Secure Cloud Saves

Fanta OFME Downloader uses Google's restricted drive.file scope. It only accesses files inside the dedicated Fanta OFME Cloud Saves folder on your personal Google Drive. The app cannot read or touch any of your other documents or personal files.
